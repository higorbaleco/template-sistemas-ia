Section opener: uppercase eyebrow, period-terminated H2, muted lead.

```jsx
<SectionHeading eyebrow="Como entregamos" title="Do gargalo ao fluxo orquestrado." lead="Quatro fases conectadas…" />
```

Headlines end in a period. Use `accent` for at most one short phrase, as in "…qualificam **clientes pelo WhatsApp.**"
