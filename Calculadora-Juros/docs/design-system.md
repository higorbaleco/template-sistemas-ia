# Design system

## Direção visual

Neumorfismo moderno com leitura premium e forte clareza numérica.

## Objetivos visuais

* sensação de produto financeiro confiável
* interfaces suaves, sem parecer infantil ou genérica
* destaque forte para números e variações
* uso cuidadoso de profundidade, sombras e contraste

## Tipografia

* título: fonte com personalidade e presença
* corpo: fonte altamente legível
* números: alinhamento e ritmo visual consistentes

## Cores

* base neutra clara para leitura
* acento principal para ações
* acento secundário para estados positivos
* cor de alerta para risco, custo e pressão de caixa

## Componentes base

* botão
* input monetário
* input percentual
* select
* card de métrica
* card de cenário
* bloco de comparação
* gráfico resumido
* tabela de amortização
* linha do tempo

## Linguagem de interface

* rótulos curtos
* textos diretos
* explicações breves no contexto
* evitar jargão sem apoio

## Formato monetário e percentual

* moeda: `R$ 10.000,00`
* percentuais: `1,25%`
* taxas mensais e anuais devem sempre indicar unidade
* campos de entrada devem preservar casas decimais corretamente

## Regras de ícones

* usar ícones vetoriais consistentes
* ícones não substituem texto crítico
* ícones devem reforçar navegação e leitura, não decorar sem função
