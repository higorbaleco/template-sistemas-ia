# PWA e mobile first

## Objetivo

A aplicação precisa se comportar como produto instalado no celular antes de se comportar como site desktop.

## Requisitos PWA

* manifest configurado
* ícones em múltiplos tamanhos
* theme color e background color definidos
* instalação suportada
* comportamento offline básico
* cache de shell da aplicação

## Prioridades mobile

* layout de uma coluna por padrão
* ações principais sempre visíveis
* cards compactos e legíveis
* inputs com alvos de toque confortáveis
* conteúdo com scroll vertical contínuo

## Regras visuais

* evitar densidade excessiva em telas pequenas
* evitar tabelas pesadas sem adaptação
* gráficos devem virar blocos responsivos
* usar expansão progressiva para detalhes

## Interação

* teclado numérico sempre que possível em campos monetários
* máscara monetária em tempo real
* feedback imediato para erro de validação
* botões com estado pressionado e foco claro

## Acessibilidade

* contraste adequado
* suporte a leitores de tela
* foco visível
* sem depender apenas de cor para informar estado
