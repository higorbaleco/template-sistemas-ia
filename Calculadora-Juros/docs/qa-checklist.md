# Checklist de qualidade

## Conteúdo

* todos os campos monetários exibem formatação correta
* percentuais mostram unidade
* textos principais não usam jargão sem explicação

## UX

* mobile first validado
* navegação principal acessível com o polegar
* estados de erro claros

## Técnica

* TypeScript strict
* core financeiro puro
* sem `any` sem necessidade real
* testes cobrindo os cálculos críticos
