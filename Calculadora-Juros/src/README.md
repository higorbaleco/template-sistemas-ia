# Estrutura de `src`

Esta pasta separa a aplicação por responsabilidades claras.

## Diretrizes

* `app` para bootstrap e rotas
* `components` para peças reutilizáveis
* `layouts` para molduras de navegação
* `modules` para features por domínio
* `financial` para cálculo puro
* `hooks` para orquestração
* `services` para persistência e exportação
* `config` para defaults e catálogos
* `types` para contratos compartilhados
* `utils` para helpers puros
