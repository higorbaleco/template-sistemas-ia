## 🎬 Como Montar Um Reel (By Padrão)

### **PADRÃO 1: POV + ABSURDO + CRÍTICA**

**Setup (20s):**
```
[VISUAL: Você em uma situação típica]
[NARRAÇÃO/LEGENDA]: "POV: Você é [profissão/situação]"
→ [Próximos 15s]: Situação escalando para o absurdo
```

**Punchline (10s):**
```
[Insight crítico disfarçado de humor]
```

**Exemplo estrutura:**
```
POV: Você é freelancer
[Mostrar: Cliente pedindo "urgente", fim de semana, prazo impossível]
[Close]: "Mas é 'rápido demais pra cobrar caro' 🤡"
```

**Tempo total:** 30-60s

---

### **PADRÃO 2: VALIDAÇÃO + SÁTIRA + INSIGHT**

**Setup (10s):**
```
[VISUAL: Expressão de frustração relatable]
[NARRAÇÃO]: "Não dá pra [X], [Y] E [Z]"
→ "Mas a gente faz tudo mesmo"
```

**Desenvolvimento (15s):**
```
[Sátira sobre o que ninguém fala]
[Humor sobre contradição]
```

**Insight (10s):**
```
[Conclusão que tira a frustração do ar]
Ex: "Mas o importante é estar vivo e consciente disso"
```

**Exemplo estrutura:**
```
"Não dá pra estudar, trabalhar, treinar E acordar 4:30"
[Mostrar: Pessoa quebrada]
"Mas a maioria faz tudo"
[Mostrar: Pessoa no trabalho, academia, etc., destruída]
"O segredo: aceitar que algo vai pro cano"
```

**Tempo total:** 30-45s

---

### **PADRÃO 3: MEME TÉCNICO + DESCONSTRUÇÃO**

**Setup (5s):**
```
[VISUAL: Mito comum sobre profissão]
[NARRAÇÃO]: "[Profissão] devem ser muito [qualidade]"
```

**Desconstrução (20s):**
```
[Mostrar realidade caricata]
[Áudio/legenda revelando ferramenta/hack que desmente o mito]
```

**Punchline (5s):**
```
[Conclusão irônica]
```

**Exemplo estrutura:**
```
"Dev deve ser muito inteligente"
[Mostrar: Dev abrindo ChatGPT, documentação, Stack Overflow]
[Narração]: "Sim, muito inteligente em saber o que pesquisar"
```

**Tempo total:** 30-45s

---

### **PADRÃO 4: ANÁLISE DADOS + SÁTIRA**

**Setup (5s):**
```
[VISUAL: Gráfico/tabela/número real]
[NARRAÇÃO]: "Análise de [X]"
```

**Enumeração Absurda (20s):**
```
[Quebrar o número em categorias ridículas]
[Mostrar diferença comparativa]
```

**Crítica Velada (10s):**
```
[Conclusão que critica desigualdade/sistema]
```

**Exemplo estrutura:**
```
"Análise: Cara que ganha 300k/mês"
[Quebrar]: "Disso, 200k vai pra carro, 50k pra roupa, 30k pra vacas..."
[Crítica]: "O carro é metade do salário, mas a carteira de trabalho é aqui embaixo"
```

**Tempo total:** 40-60s

---

### **PADRÃO 5: ABSURDO + RELIGIÃO/FÉ**

**Setup (5s):**
```
[VISUAL: Situação caótica/tensa]
[NARRAÇÃO]: [Descrição da situação]
```

**Escalação (15s):**
```
[Situação piorando]
```

**Invocação (10s):**
```
[NARRAÇÃO]: "Mermão sou fechado com [referência religiosa]"
[ou] "[Santo/Jesus] vendo eu [situação]"
```

**Punchline (5s):**
```
[Riso + absurdo + fé = relação memorável]
```

**Exemplo estrutura:**
```
[Mostrar: Pessoa em pânico, fazendo algo errado, caos]
[Narração]: "Jesus vendo eu [situação]"
[Punchline visuais: Santo, absurdo, aceitação]
```

**Tempo total:** 30-45s

## 💭 Roteiro Rápido (Template)

```
TEMA DO REEL: _______________
PADRÃO: _______________

1. HOOK (3s max)
   O QUE VEJO? [descrição visual]
   O QUE OUÇO? [áudio/narração]
   
2. SETUP (5-10s)
   QUAL É A SITUAÇÃO? [contexto]
   QUAL É O RECONHECIMENTO? [validação de sentimento]
   
3. DESENVOLVIMENTO (15-20s)
   ESCALAÇÃO: [situação piora, humor intensifica]
   SÁTIRA: [onde a crítica social entra]
   
4. PUNCHLINE (5-10s)
   O QUÊ: [o insight/conclusão]
   COMO: [linguagem, tom]
   
5. CALL-TO-ACTION IMPLÍCITO
   QUER QUE O FOLLOW: [salve? compartilhe? comente?]
```

## 🎯 Como Escolher Um Padrão

**Você quer:**

- ✅ **Máximo alcance + fácil reproduzir**  
  → Padrão 1 (POV) ou 3 (Meme Técnico)

- ✅ **Engajamento profundo + comunidade leal**  
  → Padrão 2 (Validação + Sátira)

- ✅ **Viralidade + crítica social**  
  → Padrão 1 (POV) ou 4 (Análise de dados)

- ✅ **Nicho específico/cultural**  
  → Padrão 5 (Religião) — mais arriscado

- ✅ **Crescimento de seguidores**  
  → Padrão 3 (Meme Técnico) — comunidade infinita

## ⚠️ Armadilhas Comuns

| Armadilha | Padrão Afetado | Como evitar |
|-----------|----------------|------------|
| Parecer cópia | Todos (1, 3 mais) | Adapte tema/nicho. Estrutura é pública. |
| Perder o punchline | 1, 4, 5 | 30s é limite. Teste com 5 amigos primeiro. |
| Validação fake | 2 | Fale sobre REAL. Clichê mata engajamento. |
| Dado desatualizado | 4 | Cheque número no dia que for postar. |
| Parecer insensível | 5 | Respeitar fé = tom brincalhão, não sarcástico. |
| Audiência errada | Todos | Público ≠ padrão = flopping. Conhece sua base? |

## 🎬 Exemplo Passo-a-Passo (Padrão 2 adaptado)

**Seu nicho:** Marketing digital / Startups

**Tema escolhido:** "Pressão de startup: crescer, viralizar, faturar"

**Roteiro:**

```
HOOK (3s):
  Visual: Você em pânico, laptop aberto
  Áudio: "Não dá pra crescer 10x, viralizar nos 3 canais E faturar simultâneamente..."

SETUP (5s):
  Visual: Você alternando tabs no PC (Analytics, Ads Manager, Stripe)
  Áudio: "...mas todo startup faz tudo mesmo"

DESENVOLVIMENTO (15s):
  Visual 1 (5s): Você checando Analytics às 3 da manhã
  Visual 2 (5s): Você fazendo "ajuste final" na campanha (que não muda nada)
  Visual 3 (5s): Você com 3 cafés, 0 lucro
  Áudio (todo): "A magia é aceitar que algo vai quebrar nessa equação"

PUNCHLINE (5s):
  Visual: Você com expressão de "entendi agora"
  Áudio: "Escolha qual: durmida, saúde mental, ou faturamento"
  Close: Emoji 🤡 ou sorriso irônico

CTA IMPLÍCITO: "Salva se tá vivendo isso"
```

**Tempo total:** 45s  
**Padrão:** Validação + Sátira + Insight  
**Público esperado:** Founders, marketers, empreendedores  
**Engajamento esperado:** Saves (validação de dor) + Comentários ("hahaha é exato")

## 📱 Checklist: Antes de Postar

- [ ] Hook prende em 3s? (Mostrar com amigo)
- [ ] Punchline é memorável? (Você ri de novo?)
- [ ] Tema é seu (não cópia de outro criador)?
- [ ] Legenda complementa (não repete) o vídeo?
- [ ] Hashtags/tags estão relevantes ao padrão?
- [ ] Timing certo? (horário que sua base tá online?)
- [ ] Áudio está claro/volume OK?
- [ ] Qualidade visual ≥ 720p?
