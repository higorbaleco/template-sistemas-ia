## Legenda

Skill não é prompt salvo. É uma pasta com um arquivo que o Claude carrega sozinho, só quando a tarefa bate com a descrição, e descarrega depois. Por isso dá pra ter mais de 50 instaladas sem pesar nada, o que é impossível com prompt gigante colado no começo da conversa.

Elas se dividem em seis famílias:

1. Design e UI. É onde o visual genérico de IA morre. Skill que puxa direção estética antes de codar, monta sistema de cor e proíbe as fontes padrão.

2. Imagem e vídeo. Geração e edição de peça visual por comando, do card estático ao anúncio, com o mesmo personagem entre as fotos.

3. Dev e engenharia. É onde o Claude Code vira uma equipe: teste automatizado, browser, sandbox e o Figma virando código.

4. Conteúdo e documentos. As mesmas skills que rodam por trás da criação de arquivo do Claude, docx, pdf, planilha e apresentação, mais escrita estruturada.

5. Pesquisa e memória. Deep research que cruza dezenas de fontes com citação, no lugar do Perplexity, e memória que atravessa sessões.

6. Arquitetura de prompt. As skills que ensinam o Claude a raciocinar melhor: estrutura de system prompt, persona, calibragem de tom e guardrail.

O detalhe que muda tudo: não instala as 50. Cada skill que você instala e nunca usa vira ruído que atrapalha o Claude a achar a certa. Escolhe 3 que batem com o teu trabalho, usa uma semana, e só depois adiciona.

Comenta KSJ4C que eu te mando a lista completa por categoria, com o que cada skill faz e o comando de instalar de cada uma.

Salva esse post pra não perder os comandos.
