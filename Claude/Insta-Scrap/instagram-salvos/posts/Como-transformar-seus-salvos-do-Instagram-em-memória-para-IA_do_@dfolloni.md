## Transcrição

É assim que você transforma todos os postes que você salvou no seu Instagram em memória para o Clouds. A gente vive salvando um monte de coisa, mas o problema é que depois a gente não consegue encontrar essas coisas que a gente salvou. Só que quando você compartilha isso com o Cloud, esses postes viram meio que uma memória composta que ele consegue usar para trabalhar para você. Para fazer isso, você vai abrir o Cloud na aba Clouds e você vai pedir para ele usar uma ferramenta chamada Insta-loader. Isso vai permitir que ele baixe todos os postes que você salvou no Instagram de uma vez para que o Cloud possa acessá-los depois. Depois, você vai transcrever o áudio desses postes usando o Whisper, porque assim o Cloud consegue entender o conteúdo do vídeo em si e não só a legenda dele. E aí, feito isso, o Cloud já vai conhecer tudo o que você salvou e você vai poder pedir para ele coisas como, por exemplo, montar um cardápio para mim com as receitas que eu salvei, montar a minha viagem ou o que mais você quiser. Inclusive, foi exatamente assim que eu planejei a minha logmail para o Japão. Eu passei meses salvando um monte de coisa e aí, quando chegou a hora de planejar a minha viagem, eu pedi para ele montar um roteiro baseado em todos os postes que eu tinha salvo no meu Instagram. Para facilitar a sua vida, eu montei um prompt que é só você copiar e colar para o Cloud replicar exatamente esse processo que eu acabei de explicar no vídeo.
