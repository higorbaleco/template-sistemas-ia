## Deviations From Exact Plan Code (2, both minimal and necessary)

1. **Strict-mode fix in `evolution.ts`:** The plan's constructor `constructor(private config: EvolutionConfig)` fails to compile under the project's strict tsconfig (`noUnusedLocals` → `TS6138: Property 'config' is declared but its value is never read`). The constructor body reads the `config` param directly (`config.baseUrl`, `config.apiKey`) and never uses `this.config`, so I dropped the `private` modifier: `constructor(config: EvolutionConfig)`. Behavior is identical; strict mode (a global constraint) now passes.

2. **Axios mock added to the test:** The plan's exact test code calls `connectInstance()` / `sendMessage()`, which perform real HTTP requests. Run as-is, tests 2 & 3 fail with `ECONNREFUSED 127.0.0.1:8080` (no live Evolution API). The plan's own Step 4 note states these are "mocked axios calls" / "For real integration, you'd mock axios." I honored that stated intent by adding `jest.mock('axios')` with a mocked http client, while keeping the three `it(...)` cases and every assertion verbatim. This is what makes the "implementation passes all tests" success criterion achievable offline.
