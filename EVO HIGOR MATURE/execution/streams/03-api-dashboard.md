# Stream C - API and Dashboard

## Mission

Define the admin API and the first dashboard sections required to operate agents safely.

## Instructions

1. Expose only the controls needed for creating, activating, pausing, and reviewing agents.
2. Keep API actions narrow and auditable.
3. Model chat-level overrides separately from agent-level defaults.
4. Make webhook testing and delivery logs visible in the panel.

## Output

- API surface draft
- panel navigation
- forms and controls
- access rules
- audit events
