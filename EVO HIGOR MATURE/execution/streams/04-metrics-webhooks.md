# Stream D - Metrics and Webhooks

## Mission

Define what is measured, what is emitted, and how external systems subscribe to lifecycle and message events.

## Instructions

1. Every emitted event must be replayable from storage.
2. Webhook delivery needs retries and a delivery log.
3. Metrics should cover volume, latency, health, and cost.
4. Keep webhook payloads stable and versioned.

## Output

- metric catalog
- webhook catalog
- payload draft
- retry policy
- audit requirements
