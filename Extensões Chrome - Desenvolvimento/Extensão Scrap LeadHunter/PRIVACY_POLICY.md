# Privacy Policy

## Summary

LeadHunter + Catcher stores data locally in your Chrome profile using `chrome.storage.local`.
It does not send captured leads to an external server.

## Data Collected

- Page URL and title
- Visible contact data found on pages
- User-edited lead fields
- Queue URLs added by the user
- Settings such as language and auto capture

## How Data Is Used

- To capture and organize leads locally
- To export CSV files when the user chooses to do so
- To resume queue processing after browser restart

## Data Sharing

- No captured data is transmitted to our servers.
- No third-party analytics are bundled in the extension.
- Data is only stored locally in the user’s Chrome profile.

## User Control

- Users can delete leads from the dashboard.
- Users can clear Chrome extension storage to remove all data.
- Users can stop queue processing at any time.

## Security

- The extension follows Chrome extension security boundaries.
- Users should review leads before importing them into other systems.

## Changes

This policy may be updated when the extension’s local data model changes.
