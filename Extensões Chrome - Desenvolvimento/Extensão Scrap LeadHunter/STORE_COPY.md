# Chrome Web Store Copy

## Short description

Capture and organize leads locally while browsing. Queue URLs, auto-capture visible contacts, and export CSV.

## Full description

LeadHunter + Catcher is a local-first Chrome extension for lead capture.

It can:

- Capture contacts from the page you are viewing
- Process a queue of URLs automatically inside Chrome
- Detect leads on Google Search, Google Maps, LinkedIn, OLX, directories, and institutional pages
- Save everything locally in your Chrome profile
- Export leads to CSV for CRM or spreadsheet workflows
- Let you edit, filter, and remove leads in a dashboard

The extension does not require a backend and does not transmit captured leads to external servers.

## Suggested permissions explanation

- `storage`: saves leads, settings, and queue state locally
- `tabs`: opens temporary tabs for queue processing and detects the active tab for manual capture
- `alarms`: helps resume queue processing reliably after service worker suspension
