# Legacy Heavy

Esta pasta guarda o fluxo antigo e pesado do projeto para consulta, comparação e eventual descarte.

## O que ficou aqui

- Backend Flask
- Scrapers e validação pesada
- Pipeline antigo de busca/saúde/rate limit
- Assets e documentação antiga da versão robusta

## O que não faz parte da extensão nova

- Nada desta pasta entra no ZIP da extensão Chrome
- O produto principal agora vive em `chrome-extension/`

## Observação

Se o fluxo pesado não fizer mais sentido depois da análise, esta pasta pode ser removida sem afetar a extensão leve.
