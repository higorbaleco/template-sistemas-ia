## Regras de Uso dos Hooks

### DO (Fazer)
1. **Teste 2-3 hooks por tema** — gravar o mesmo conteúdo com hooks diferentes
2. **Entregue nos primeiros 3 segundos** — o hook PRECISA parar o scroll
3. **Use números específicos** — "R$47K" > "muito dinheiro"
4. **Fale diretamente para UMA pessoa** — "você" > "vocês"/"galera"
5. **Conecte ao CTA do final** — o hook promete, o CTA entrega
6. **Adapte ao tom do Mago** — autoridade com leveza, nunca robótico

### DON'T (Não Fazer)
1. **Não use clickbait sem entrega** — frustração mata retenção
2. **Não comece com "Fala galera"** — genérico, não para scroll
3. **Não use hooks longos** — máximo 2 frases nos primeiros 2s
4. **Não copie hooks exatos de concorrentes** — adapte sempre
5. **Não use o mesmo hook mais de 1x em 30 dias**
6. **Não comece com pergunta fraca** — "Sabia que..." é fraco, "Você está perdendo vendas porque..." é forte

## Fórmulas de Hook (Templates)

### Fórmula 1: Gap + Urgência
```
"[Coisa que público não sabe] e isso está [consequência negativa]"
```
Ex: "Essa configuração do WhatsApp está escondida e ela TRIPLICA suas respostas"

### Fórmula 2: Prova + Curiosidade
```
"[Resultado impressionante] — e levou só [tempo curto] para configurar"
```
Ex: "1.200 mensagens respondidas em 1 dia — e levou 15 minutos para configurar"

### Fórmula 3: Confronto + Valor
```
"[Ação que público faz] está [consequência] — faz ISSO em vez disso"
```
Ex: "Responder WhatsApp manualmente está te custando R$5K/mês — faz isso em vez disso"

### Fórmula 4: Comparação Temporal
```
"Em [ano passado] você fazia [coisa antiga]. Em 2026, [coisa nova] faz isso em [tempo]"
```
Ex: "Em 2024 você contratava atendente. Em 2026, uma IA faz isso em 3 segundos"

### Fórmula 5: Social Proof + FOMO
```
"[Número] de [público] já estão usando [coisa]. Você vai ficar de fora?"
```
Ex: "85% das empresas que faturam 7 dígitos já usam IA no WhatsApp. E você?"
