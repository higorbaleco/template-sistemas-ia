Análise de 35 posts humorísticos de Instagram revelou 5 padrões dominantes para conteúdo de Awareness/Topo de Funil.

**Why:** O usuário identificou que falta conteúdo de Topo/Awareness em seu perfil, e conteúdos "engraçadinhos" são ótima estratégia para isso.

**How to apply:** Usar esses padrões ao gerar pautas de awareness para qualquer nicho. São universais o suficiente para adaptar.

---

## Os 5 Padrões

### 1. Reel Curto + Áudio Viral (70% dos posts)
- Formato: vertical, 15-60 segundos
- Áudio carrega 70% da mensagem
- Transições rápidas, texto sobreposto mínimo
- Mensagem entregue em < 10 segundos

### 2. Caption Minimalista (85% dos posts)
- 1-3 linhas máximo
- Linguagem coloquial/gíria brasileira
- 1-2 emojis estratégicos (nunca mais que 3)
- Hashtags para alcance (#meme, #humor, #viral, #explorar)
- O visual faz o trabalho pesado, caption só reforça

### 3. Nicho + Universalidade (64% dos posts)
- Humor sobre profissão/hobby específico que ressoa com problema universal
- Fórmula: "Contexto de nicho" + "Problema que todo mundo tem"
- Exemplo: Dev usando ChatGPT (nicho) + todo mundo precisa de ajuda (universal)
- Inside joke que outsiders ainda conseguem entender

### 4. Contraste/Split Narrativo (56% dos posts)
- Estrutura "expectativa vs. realidade"
- Funciona em: promessa vs. realidade, antes vs. depois, tipo A vs. tipo B
- Punchline visual > punchline textual
- Facilita compartilhamento ("Qual tipo você é?")

### 5. Comunidade Constrói a Piada (96% dos posts)
- Posts que deixam brechas para comentários expandirem o humor
- Conteúdo não é engraçado isolado — a comunidade o torna engraçado
- Post com 100 comentários criativos > post com 10K likes solitários
- Não fechar o humor sozinho; deixar espaço para participação

---

## Fórmula Ouro
**Nicho específico + problema universal + exagero bem-dosado = viralidade**

## Engajamento por Tipo de Humor

| Tipo | Frequência | Avg Likes | Avg Comments | Melhor Para |
|------|-----------|-----------|-------------|-------------|
| Autocrítica | 52% | 102K | 800 | Confiança + vínculo |
| Situacional | 44% | 75K | 350 | Nichos profissionais |
| Absurdo | 40% | 28K | 280 | Viralidade máxima (shares) |
| Ironia | 36% | 33K | 400 | Insider communities |
| Motivação disfarçada | 16% | 10K | ~100 | Manter engajado |
