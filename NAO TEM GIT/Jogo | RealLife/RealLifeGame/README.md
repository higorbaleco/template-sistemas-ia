# RealLife Game

A hybrid life simulation/clicker/tycoon game inspired by The Sims, Rich Life, Finance Clicker, and Business Empire: Richman.

## Project Structure

- `/scenes/` - All game scenes (characters, buildings, UI, managers, items)
- `/scripts/` - Game logic and utility scripts
- `/assets/` - 3D models, textures, audio, fonts
- `/resources/` - Custom resources and data files

## Development Setup

1. Install Godot Engine 4.x (https://godotengine.org/download)
2. Open this project in Godot Editor
3. Start developing!

## Features Planned

- Life Simulation (character needs, relationships, daily activities)
- Clicker/Finance Mechanics (tap for income, investments, upgrades)
- Business/Tycoon Elements (property management, employees, economy)
