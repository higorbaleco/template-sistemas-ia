# 08. Pós-venda

## 8.1 Objetivo

Transformar suporte genérico em gestão contínua tangível.

## 8.2 Entregas recorrentes possíveis

- relatório;
- monitoramento;
- análise de conversas;
- correções;
- atualização de base;
- otimização;
- treinamento;
- acompanhamento;
- alertas;
- revisão de indicadores;
- plano do próximo período.

## 8.3 Suporte

Definir:

- canal;
- horário;
- SLA;
- criticidade;
- quantidade de solicitações;
- tipo de solicitação;
- o que está incluso;
- o que é projeto adicional.

## 8.4 Renovação

Deve ser baseada em:

- valor percebido;
- uso;
- economia;
- estabilidade;
- impacto;
- evolução;
- próximos objetivos.

## 8.5 Upsell

- mais canais;
- mais volume;
- integração;
- novas unidades;
- novos agentes;
- dashboards;
- CRM;
- automações;
- contingência.
