# 12. Prompts

## Prompt mestre para IA

Toda IA deve receber:

- contexto da empresa;
- produto;
- ICP;
- objetivo;
- canal;
- restrições;
- linguagem;
- base de cases;
- regras de negócio;
- estrutura de saída.

## Prompt para Claude Design

Função do Claude Design:

- diagramar;
- aplicar identidade;
- organizar;
- criar hierarquia;
- adaptar visualmente;
- preservar conteúdo.

Não deve:

- redefinir estratégia;
- inventar preço;
- alterar escopo;
- criar promessa;
- mudar posicionamento;
- omitir risco;
- modificar regra de negócio.
