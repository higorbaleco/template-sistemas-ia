# 05. Sistema Comercial, Prospecção e Scripts

## Problema atual

### CONFIRMADO

- vendas voláteis;
- pouca rotina de prospecção;
- necessidade de repensar ICP e abordagem;
- chats abertos;
- leads perdidos;
- falta de visibilidade;
- ausência de próxima ação;
- propostas artesanais;
- falta de biblioteca operacional.

## Processo desejado

O painel deve responder:

- quem abordar;
- por qual canal;
- qual segmento;
- qual problema observar;
- qual produto oferecer;
- qual script usar;
- qual próxima ação;
- qual diagnóstico;
- qual proposta;
- qual case;
- qual objeção.

## Pipeline

1. Conta identificada
2. Problema observado
3. Contato encontrado
4. Abordagem realizada
5. Resposta
6. Qualificação
7. Diagnóstico agendado
8. Diagnóstico realizado
9. Proposta
10. Negociação
11. Fechado
12. Perdido
13. Nutrição
14. Reativação

## Regra central

Nenhum lead sem:

- próxima ação;
- data;
- responsável;
- status;
- histórico.

## Cadência histórica

Canais citados:

- LinkedIn;

- Apollo;
- Lusha;
- e-mail;
- Instagram;
- cold call;
- WhatsApp.

Já houve discussão de cadência D0 a D5.

Metas históricas:

- média aproximada de 13%.

## Venda contextual

Higor prefere abordagem baseada em:

- tentativa real de compra;
- demora no WhatsApp;
- atendimento ruim;
- problema no Marketplace;
- conteúdo publicado;
- visita presencial;
- presente;
- indicação;
- relação existente.

## Estrutura de script contextual

1. Observação concreta
2. Problema
3. Consequência
4. Credencial
5. Hipótese
6. Pergunta
7. Convite

## Abordagens rejeitadas

- “Notei que sua empresa...”;
- elogio genérico;
- spam;
- texto longo;
- falsa personalização;
- discurso abstrato sobre IA;
- promessa sem contexto.
