# 06. Diagnósticos, Propostas e Fechamento

## Objetivo do diagnóstico

Transformar conversa em decisão comercial.

Deve identificar:

- contexto;
- problema;
- impacto;
- processo;
- volume;
- pessoas;
- tecnologia;
- urgência;
- orçamento;
- decisor;
- risco;
- produto.

## Regra de geração

A IA deve preencher blocos aprovados, não inventar a proposta.

Campos:

- empresa;
- problema;
- produto;
- escopo;
- prazo;
- preço;
- recorrência;
- plataforma;
- consumo;
- case;
- condição;
- exclusão.
