## COMO USAR ESSE CHECKLIST

1. **DIÁRIO:** Cole uma cópia no seu Desktop. Faça todos os dias (5 min preencher)

2. **SEMANAL:** Toda sexta-feira, preencha completo (30 min)

3. **MENSAL:** 1º dia do mês (1h análise)

4. **SINCRONIZE COM DASHBOARD:** Dados do checklist devem bater com Dashboard

5. **MUDE O QUE NÃO FUNCIONA:** Se tá sempre abaixo da meta, mude estratégia
