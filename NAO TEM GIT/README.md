# NAO TEM GIT

Workspace de triagem para projetos, sistemas e pastas operacionais que ainda nao
estavam organizados como repositorios Git no nivel principal.

## Como ler este workspace

- Os projetos com repositorio proprio ficam em subpastas.
- Algumas pastas sao so contenedores e precisam ser avaliadas antes de virar
  repo.
- Pastas com `README.md` agora ja tem um ponto de entrada minimo para Git.

## Regra usada

Entrou aqui tudo que era pasta de trabalho e **nao** tinha `.git` proprio no
primeiro nivel do projeto.

## Proximo passo recomendado

1. Revisar quais pastas vao virar repo proprio.
2. Garantir `.gitignore` e README em cada raiz escolhida.
3. Inicializar o repo ou conectar o remote.
4. Fazer o primeiro commit com a documentacao.
