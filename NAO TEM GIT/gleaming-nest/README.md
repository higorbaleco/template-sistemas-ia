# Gleaming Nest

Arquitetura inicial do Gleaming Nest, um sistema de planejamento e analise de conteudo baseado em:

- React + Vite + TypeScript
- Tailwind + shadcn/ui
- Supabase Edge Functions
- Notion como base principal de dados
- Anthropic para analise de roteiros
- Apify para ingestao de conteudos do Instagram

## O que este projeto faz

- Organiza ganchos de conteudo
- Centraliza inspiracoes e saves
- Mantem roteiros em fluxo de producao
- Analisa roteiros com a Iada
- Executa ingestao automatica diaria
