# Referências históricas — Z-API

Esta pasta preserva os quatro PDFs históricos enviados como referência:

- Design de solução
- Modelos comerciais
- Plano de parcerias

Eles não são instruções atuais nem definem automaticamente os preços da Avraham. Foram usados para extrair padrões de arquitetura comercial, categorias de Partner, jornada de integração, negociação por volume e estrutura de proposta.
