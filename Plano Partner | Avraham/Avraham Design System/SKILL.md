If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Non-negotiables: never use emoji as icons (use the icon system); never use the em dash; every surface must work in dark (default) and be checked against the light theme; the 60px command grid is the signature background and is never removed.
