One Lucide glyph — the only icon system Avraham uses; never hand-draw an SVG.

```jsx
<Icon name="bot" size={22} color="var(--emerald-500)" />
```

The page must load the Lucide CDN script (`https://unpkg.com/lucide@latest`) before mounting. Kebab-case names only. Stroke weight stays at 1.75 for UI, 2 for 16px inline glyphs.
