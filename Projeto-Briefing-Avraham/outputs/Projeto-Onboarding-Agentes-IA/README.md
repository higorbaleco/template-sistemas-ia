# Projeto Onboarding de Clientes e Agentes de IA

Esta pasta centraliza o sistema comercial e operacional para vender, precificar, onboarding e provar ROI de projetos de agentes de IA.

## Estrutura

- `documentos/`
  - `processo-onboarding-agentes-ia.md`: visao geral do processo, fluxos e criterios de maturidade.
  - `briefing-cliente-agente-ia.md`: briefing completo para descobrir dores, contexto, operacao e requisitos do agente.
  - `sistema-comercial-onboarding-roi.md`: playbook completo, da ligacao inicial ate o relatorio mensal de ROI.
- `planilhas/`
  - `sistema-comercial-onboarding-roi.xlsx`: calculadora importavel no Google Sheets com fit score, escopo, horas, preco, mensalidade, custos de tokens e ROI.
- `produto/`
  - `visao-produto-site-calculadora.md`: recomendacao de produto para transformar o material em site, calculadora inteligente ou gerador de agentes.

## Como usar hoje

1. Use o roteiro de pre-venda para qualificar o lead.
2. Registre a oportunidade na planilha.
3. Confira fit score, impacto financeiro e estimativa de horas/preco.
4. Use o playbook para conduzir a reuniao de proposta com dores e numeros.
5. Quando fechar, rode o briefing completo.
6. Transforme as respostas no plano de onboarding do cliente.
7. Acompanhe mensalmente entregaveis, impacto financeiro, custos e ROI.
