# Novos arquivos de apresentações Avraham

## Arquivos criados

### Disparos e Reativação

- `produto-disparos.html`
- 10 telas em formato 1320 × 1080.
- Versão principal com alternância entre fundos escuros e claros.
- Complementa o arquivo já existente `produto-disparos-light.html`.

### Infraestrutura e Contingência para WhatsApp

- `produto-infraestrutura-whatsapp.html`
- `produto-infraestrutura-whatsapp-light.html`
- 10 telas em cada versão.
- Aborda arquitetura, contingência, distribuição, monitoramento, reposição, capacidade e governança operacional.

### Índice

- `indice-apresentacoes.html`
- Página simples para navegar entre a apresentação institucional e as apresentações individuais de produtos.
- Deve ser colocada na mesma pasta dos demais arquivos HTML.

## Estrutura editorial utilizada

1. Capa e proposta central.
2. Problema operacional.
3. Diferença entre improviso e estrutura.
4. Transformação do ponto A para o ponto B.
5. Componentes ou aplicações práticas.
6. Processo de implantação.
7. Experiência, capacidade ou governança.
8. Critérios de aderência.
9. Benefícios ou segmentos prioritários.
10. Próximo passo e chamada para diagnóstico.

## Observação

Os arquivos novos são autocontidos: o CSS está incorporado no próprio HTML. A fonte Inter é carregada pelo Google Fonts e possui fontes alternativas do sistema caso o carregamento externo não esteja disponível.
