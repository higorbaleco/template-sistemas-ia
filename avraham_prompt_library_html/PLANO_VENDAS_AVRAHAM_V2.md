## PARTE 3: CADÊNCIA ZAPIER INTELIGENTE

Objetivo: Automação que NÃO parece spam, baseada em comportamento

### Trigger 1: Enviou WhatsApp
**Ação:** Iniciar cadência automática

**Dia 0:** Primeira mensagem (você faz manualmente, personalizada)
**Dia 2:** Se não respondeu = lembrança leve (Zapier)
```
"Oi, chegou minha mensagem anterior? Sem pressa, mas achei que poderia ser útil pra vocês."
```

**Dia 5:** Se respondeu positivo = agenda call (você)
Se respondeu negativo = arquivo (talvez próximo semestre)
Se não respondeu = envia case (Zapier)
```
Anexar: PDF case similar ao negócio dele
"Seguinte, vi que ainda não respondi. Achei que esse case poderia fazer mais sentido. 
Depois tá aberto pra conversar?"
```

**Dia 7:** Se ainda sem resposta = move pra fila "reativar em 30 dias"

### Trigger 2: Respondeu positivo
**Ações:**
- Agendar call (você)
- Enviar calendly link (Zapier)
- Preparar deck diagnóstico (você)

**Call de 20min:**
1. "Qual é a situação de atendimento de vocês hoje?" (5min)
2. Mostrar case relevante (5min)
3. "Se a gente implementasse isso, qual impacto teria?" (5min)
4. "Qual próximo passo?" (5min)

Se virou lead quente:
- Agendar diagnóstico (30 min, com você + CTO/Dev)
- Enviar proposta simplificada (5-10K ou 20-30K, conforme fit)

### Trigger 3: Respondeu negativo OU "Depois"
**Ações:**
- Arquivo na base "Reativar"
- Reativar em 30 dias com novo ângulo
