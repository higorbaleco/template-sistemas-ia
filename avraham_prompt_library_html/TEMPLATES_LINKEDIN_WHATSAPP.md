## QUANDO USAR

| Situação | Usar |
|----------|------|
| Viu post relevante no LinkedIn | Comment template |
| Engajou no seu comentário | WhatsApp primeiro contato |
| Não respondeu em 2 dias | Follow-up dia 2 |
| Respondeu positivo mas não vem pra call | Follow-up dia 5 + case |
| Confirmou call | Pre-call briefing |
| Call foi positivo | Diagnostic proposal |
| Diagnostic foi positivo | Commercial proposal |

---

## REGRAS OURO

✓ Sempre personalize com detalhe específico que você viu/aprendeu  
✓ Nunca template genérico puro - adapte sempre  
✓ Primeira mensagem: educação, não venda  
✓ Segunda mensagem (se não responde): lembrança leve  
✓ Terceira mensagem: valor concreto (case/infográfico)  
✓ Nunca terceira mensagem vendendo - só educando  
✓ Se respondeu positivo: call rápido, sem demora  
✓ Call: 80% escuta, 20% apresentação  
✓ Diagnostic: técnico, sem pressão comercial  
✓ Proposta: simples, sem surpresas

## ANTI-PATTERNS (NÃO faça)

✗ "Oi [Nome]! Tudo bem? Tenho uma solução que pode te interessar..."  
✗ "Clica aqui para saber mais sobre nossa solução"  
✗ "Precisamos conversar sobre como escalar seu atendimento"  
✗ "Você está interessado em aumentar suas vendas?"  
✗ "Vem conhecer nossa plataforma"  
✗ "Tenho um ótimo case pra te mostrar" (sem contexto)  
✗ Três mensagens no mesmo dia  
✗ Chamar no phone antes de warm-up  
✗ Enviar 10 templates iguais pra 10 pessoas (vai parecer spam)  
✗ "Não vi seu retorno..." (guilt trip)
