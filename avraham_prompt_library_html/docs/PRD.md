# Product Requirements Document (PRD)

## 1. Objetivo
Criar e modernizar a "Avraham Prompt Library", uma biblioteca estática, performática e elegante para armazenamento, busca e gerenciamento de prompts úteis para Inteligência Artificial (IA). O sistema deve ser responsivo e funcionar totalmente offline no navegador.

## 2. Escopo
- Interface web com barra de pesquisa para buscar prompts.
- Filtros por plataforma (ex: ChatGPT, Claude, etc), aplicação e tipo.
- Sistema de favoritos salvo localmente (LocalStorage).
- Visualização em Grade e Lista.
- Suporte a tema Claro e Escuro (Dark Mode/Light Mode).
- Criação, importação e exportação de prompts personalizados.
- Totalmente estático, hospedado no Netlify (sem backend).

## 3. Público-Alvo
Desenvolvedores, engenheiros de prompt, pesquisadores e entusiastas de Inteligência Artificial que buscam centralizar, padronizar e otimizar suas iterações com diferentes LLMs através de um catálogo pessoal ou curadoria de prompts.

## 4. Métricas de Sucesso
- 100% de acessibilidade WCAG 2.1 AA alcançada e comprovada no Lighthouse.
- Perfomance nota 100 no Google Lighthouse (página estática rápida).
- Contraste visual > 4.5:1 em todos os elementos de texto nos dois temas.
- Hospedagem concluída com sucesso e funcional no Netlify.
