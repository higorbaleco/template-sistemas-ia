# ICP Qualification

## Objetivo

Decidir se uma conta merece capacidade comercial.

Na V1, qualificação deve ser simples e explicável.

## Input

Account enriquecida.

## Output

```text
ICP_APPROVED
ICP_REJECTED
ICP_REVIEW
```

## Critérios gerais V1

- pertence a segmento relevante;
- possui canal utilizável;
- aparenta operação real;
- pode ter fit com pelo menos um produto;
- não está em lista de bloqueio.

## Critérios não obrigatórios

- faturamento conhecido;
- número exato de funcionários;
- tecnologia utilizada;
- orçamento.

Esses dados podem melhorar a priorização, mas não devem impedir a V1.

## Regra

ICP não escolhe produto.

Isso é responsabilidade do Product Router.
