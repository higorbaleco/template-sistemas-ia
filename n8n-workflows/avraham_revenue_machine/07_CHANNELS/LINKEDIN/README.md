# LinkedIn Worker

## Ações possíveis

- conexão;
- mensagem;
- follow-up;
- leitura de resposta;
- atualização de status.

## Objetivo

Criar outra porta de entrada para a mesma Account.

## Regra

Uma resposta no LinkedIn deve pausar a cadência comercial nos demais canais até o Conversation Hub decidir a próxima ação.
