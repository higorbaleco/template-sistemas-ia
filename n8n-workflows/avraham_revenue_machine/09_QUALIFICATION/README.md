# Qualification Engine

## Objetivo

Descobrir se existe oportunidade comercial real antes de consumir a agenda do Higor.

## Input

Resposta positiva ou abertura comercial.

## Output

```text
QUALIFIED
UNQUALIFIED
NURTURE
NEEDS_HUMAN
```

## Campos desejados

Dependem do produto, mas podem incluir:

- problema;
- volume;
- urgência;
- operação atual;
- estrutura;
- decisor;
- necessidade;
- prazo;
- ticket potencial;
- contexto técnico.

## Regra

Perguntar somente o necessário para determinar o próximo passo.

Não transformar qualificação em interrogatório.
