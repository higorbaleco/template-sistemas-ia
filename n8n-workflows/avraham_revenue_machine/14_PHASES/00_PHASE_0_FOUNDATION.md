# Fase 0 — Fundação

## Objetivo

Criar uma base que permita adicionar fluxos sem reconstruir tudo.

## Entregáveis

- Account Database;
- Contact Model;
- Event Schema;
- estados globais;
- Campaign Model;
- logs;
- deduplicação;
- IDs;
- regras de opt-out;
- ambiente de teste.

## Critério de conclusão

Uma Account deve conseguir entrar manualmente na base, percorrer estados e gerar eventos sem depender de nenhum canal.
