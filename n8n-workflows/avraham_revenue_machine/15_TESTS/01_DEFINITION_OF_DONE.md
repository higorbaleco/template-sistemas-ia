# Definition of Done

Um bloco está pronto quando:

- [ ] recebe input no formato esperado;
- [ ] valida input;
- [ ] processa cenário normal;
- [ ] processa erro;
- [ ] registra log;
- [ ] gera evento;
- [ ] produz output padronizado;
- [ ] não duplica ações em retry;
- [ ] possui documentação;
- [ ] possui teste manual;
- [ ] possui teste de integração com próximo bloco;
- [ ] pode ser desligado sem corromper dados anteriores.
